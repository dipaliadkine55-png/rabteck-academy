    Semantic Component Architecture Gallery

    Reference guide for semantic tags and accessible usage in enterprise platforms.

    <header> & <nav>

    Landmarks

    Defines introductory content and primary site navigation link structures.

    <header role="banner">
  <nav aria-label="Main Navigation">
    <ul role="list">...</ul>
  </nav>
</header>

    <dialog>

    Overlay

    Native HTML modal dialog providing built-in focus trap and ESC listener.

    <dialog id="myModal" aria-labelledby="title">
  <h2 id="title">Modal Title</h2>
  <button autofocus>Close</button>
</dialog>

    <meter> & <progress>

    Metrics

    Represents scalar measurements within a known range, or completion status.

    <meter value="0.6" min="0" max="1">60%</meter>
<progress value="75" max="100">75%</progress>

    <time> & <mark>

    Inline Semantics

    Machine-readable timestamps and highlighted context text strings.

    <time datetime="2026-10-08">Today</time>
<mark class="bg-amber-200">Highlighted</mark>

    This modal component features:

    • Dynamic aria-modal="true" implicit attributes
